Why I’m building this

Smartphone diagnostics draws on power, timing, storage, and signal relationships. This project organizes those subjects into a bilingual reference for learning how to reason about hardware.

Current release

Fifteen lessons across Core Concepts, Power Management, and Clocks & Timing, with search and a linked glossary. The remaining domains are planned. Content is educational draft material awaiting technical review; the application does not diagnose devices automatically.
